Hi! ini adalah post kedua saya, kali ini saya akan share bagaimana mereset printer epson l series yang error.

Sebelumnya, kenapa sih printer error itu? Biasanya sih karena ada beberapa faktor. Salah satunya yang paling sering terjadi adalah karena printer sudah mencetak terlalu banyak halaman, dengan begitu ini yang menyebabkan printer perlu direset.

Oke jadi jangan panik kalo printer kamu error, yang perlu kamu lakukan adalah reset printer epson l series kamu. Caranya gampang kok, pertama download dulu resetternya, kamu bisa download di luar sana atau kamu bisa download [link disini](http://lynk.id/jsbyma/s/kreo4360kwzj).

Kalo tidak bisa di download, coba matikan Real-time protection di windows kamu, soalnya seringkali ada beberapa file yang terdeteksi sebagai virus padahal tidak.
Caranya adalah:
1. Buka Windows Security
2. Pilih menu Virus & threat protection.
3. Klik Manage settings (di bawah tulisan Virus & threat protection settings).
4. Ubah posisi Real-time protection menjadi Off.

Setelah kamu download resetternya, kamu perlu mengekstrak filenya, lalu ikuti langkah dibawah ini:

**Langkah 1: Menjalankan Resetter**

1. Hubungkan printer ke komputer menggunakan Kabel USB (Jangan gunakan koneksi Wi-Fi).
2. Setelah aplikasinya terbuka, klik tombol Select di bagian atas.
3. Klik kanan pada AdjProg.exe lalu pilih Run as administrator.
4. Pada kolom Model Name, pilih seri printer kamu.
5. Pada bagian Port, ubah dari Auto Selection menjadi port USB yang terdeteksi printer Epson kamu
<hr>

**Langkah 2: Proses Reset Waste Ink Pad**

1. Pilih menu **Particular adjustment mode**.
2. Akan muncul daftar menu baru. Cari dan pilih menu **Waste ink pad counter**, lalu klik OK.
3. Di jendela berikutnya, beri tanda centang (✓) pada kotak **Main pad counter** (dan kotak counter lainnya jika ada di bawahnya, seperti Platen pad counter).
4. Klik tombol **Check** terlebih dahulu untuk melihat persentase kapasitas pembuangan saat ini. Biasanya angkanya sudah mencapai 100% atau mendekati.
5. Centang kembali kotak **Main pad counter**, lalu klik tombol **Initialize**.
6. Akan muncul jendela konfirmasi kecil, klik OK. Tunggu beberapa saat hingga proses reset sistem selesai.
<hr>

**Langkah 3: Tahap Akhir**
1. Jika proses berhasil, aplikasi akan memunculkan perintah: "Please turn off the printer".
2. Matikan printer Anda dengan menekan tombol power fisik pada printer.
3. Setelah printer mati, klik OK pada jendela aplikasi di komputer, lalu tutup program resetter tersebut.
4. Nyalakan kembali printer Epson Anda.

That's it! printer kamu sudah berhasil direset. Semoga membantu! :D
